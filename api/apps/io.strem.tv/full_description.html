🇺🇸 Stremio for webOS — Modern OLED & 4K Edition (v5.0.4)

High-performance Stremio client designed for modern LG Smart TVs with 64-bit ARM64 processors running webOS 5.0 up to webOS 25+.

📺 Hardware Compatibility:

  • LG OLED: CX, C1, C2, C3, C4, C5, G1, G2, G3, G4, G5, B1..B4
  • LG QNED / NanoCell / 4K UHD: 2020 to 2025+ models (webOS 5.0, 6.0, 22, 23, 24, 25)
  • Execution Mode: Fully compatible with both Root (Homebrew Channel) and Developer Mode (no root).

🚀 v5.0.4 Key Features & Optimizations:

  • Decoder Stall Auto-Recovery Watchdog: Prevents freezing mid-movie by nudging the hardware pipeline if a stall is detected.
  • LG Magic Remote & Color Keys: Full mapping for Red (Search), Green (Home), Yellow (Library), Blue (Discover), media controls and wheel scrolling.
  • Native Audio Track Selection Fix: Automatically selects your preferred audio language configured in your Stremio profile.
  • Turbo RAM Cache (Zero Stutter): Pre-caches UI assets in RAM for 60 FPS catalog navigation.
  • 4K HDR & Dolby Vision: Direct hardware-accelerated video decoding.
