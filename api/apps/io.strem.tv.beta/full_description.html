🇺🇸 Stremio Lite & Ultra Lite LG — Legacy Low-RAM Edition (v5.0.2)

Ultra-lightweight Stremio client designed for legacy rooted LG Smart TVs (webOS 3.x & 4.x / 2016–2019) with Chromium 53 engine and limited RAM (~512MB–1GB).

⚡ Dual Performance Profiles:

  • Versão A — Stremio Lite (Balanced): High-definition logos in Hero banner, ambient background, downscaled poster textures.
  • Versão C — Stremio Ultra Lite (Maximum Memory Free): Zero background textures on GPU, pure text logos, text-based episode lists. Ideal for 512MB RAM TVs (prevents TV reboots / OOM crashes).
  • Switch instantly in Settings → Performance Mode!

📺 Hardware Compatibility:

  • 2018–2019 Models: UK, UM, LK, SK, SM, OLED B8, C8, B9, C9 (webOS 4.x)
  • 2016–2017 Models: UH, UJ, LJ, B7, C7 (webOS 3.x)
  • Requirement: Rooted LG TV with Homebrew Channel installed.

🛠️ Key Fixes & Features:

  • Native Video Trailers: Hardware-accelerated MP4 player replaces memory-heavy YouTube iframe.
  • Fixed Back & Search Navigation: Backspace key properly deletes text without crashing or closing the app; double-back event debounced.
  • Zero Memory Buffers: Node.js local proxy avoids RAM buffer hoarding and background CPU spikes.
