🇺🇸 Stremio Lite LG — Legacy Low-RAM Edition (v5.0.2)

Ultra-lightweight Stremio client designed for legacy rooted LG Smart TVs (webOS 3.x & 4.x / 2016–2019) with Chromium 53 engine and limited RAM (~512MB–1GB).

📺 Hardware Compatibility:

  • 2018–2019 Models: UK, UM, LK, SK, SM, OLED B8, C8, B9, C9 (webOS 4.x)
  • 2016–2017 Models: UH, UJ, LJ, B7, C7 (webOS 3.x)
  • Requirement: Rooted LG TV with Homebrew Channel installed.

⚡ Architecture & Memory Optimizations:

  • GPU Texture Recycling: Unmounts off-screen posters freeing up to 120MB of VRAM, preventing out-of-memory crashes on Chromium 53.
  • Metahub Proxy Downscaling: Automatically loads downscaled poster textures for low-RAM stability.
  • Multi-Language Support (i18n): English, Portuguese (BR/PT), Spanish, French, German, Italian, Russian, Turkish.
  • 32-bit ARM Binaries: Node.js and FFmpeg binaries built for armv7.
